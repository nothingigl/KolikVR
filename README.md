# AutoScope Garage 02 / KolikVR

Учебная лаборатория с реконструкциями Tesla Model 3, Hyundai IONIQ 5 и Nissan LEAF.

Подробности обновления, источники характеристик и допущения: [Garage v2](docs/GARAGE-V2.md).

Самостоятельное клиентское приложение: React, TypeScript, Vite, Three.js, WebXR и PWA. Без регистрации, сервера, внешних моделей и CDN. Интерфейс — русский.

## Запуск

Готовые архивы сборок находятся в `releases/`; актуальная версия — `AutoScope-v2.0.0.zip`.

Требуется Node.js 22.12+ (либо поддерживаемая более новая LTS), npm.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`dist/` — готовый статический сайт. Публикуйте содержимое этой папки в корне HTTPS-домена. Для GitHub Pages в подпапке `/KolikVR/` нужна дополнительная настройка базового пути; текущая сборка рассчитана на отдельный домен. Не открывайте index.html как file://. Сервис-воркер включён только в production-сборке, HTTPS или localhost.

## Что реализовано

- Четыре раздела: автомобиль, пять механизмов, устройство VR-очков, инструкция.
- Лёгкое статичное превью до запуска 3D. Движок и сцены импортируются динамически.
- Путь энергии, синхронный двигатель с постоянными магнитами, редуктор и дифференциал, рекуперация, батарея с охлаждением.
- Запуск, пауза, сброс; тяга, тормоз, дорожная нагрузка, отношение 3–10, поворот, заряд, охлаждение, скорость демонстрации.
- Процедурные модели, выбор деталей мышью/лучом/кнопками, скрытие корпуса, разнесение, камера с мышью, касаниями и клавиатурой.
- Интерактивная SVG-альтернатива 2D с той же симуляцией. Автопереход при ошибке WebGL или потере контекста.
- WebXR: реальная проверка immersive-vr, вход по действию пользователя, лучи двух контроллеров, пространственная панель, управление всеми параметрами, разборкой, паузой, выбором сцен/деталей, сбросом и выходом. Удержание боковой кнопки переносит модель; стик поворачивает и меняет расстояние.
- PWA: manifest, PNG-иконки 192/512, отложенное обновление, выбранные пользователем сцены со всеми транзитивными зависимостями. Никакого автоматического скачивания каталога.
- Уровни качества, ограниченный pixel ratio, instancing ячеек, LOD батареи, упрощённые материалы, освобождение геометрий/материалов, остановка в фоне. Рендер по изменениям на паузе.

## Архитектура

| Каталог | Назначение |
| --- | --- |
| `src/sim/model.ts` | Независимое состояние и расчёт, контракт `LearningModule` |
| `src/scenes/` | Отдельно загружаемые процедурные 3D-модули |
| `src/views/renderer.ts` | Жизненный цикл одной активной 3D-сцены, качество, освобождение ресурсов |
| `src/views/Diagram.tsx` | 2D-представление того же состояния |
| `src/adapters/` | Мышь, касания, клавиатура и пространственное XR-управление |
| `src/i18n/` | Русские тексты интерфейса и учебных материалов, основа будущего перевода |
| `src/offline/`, `public/sw.js` | Обмен с service worker, выборочное кэширование |
| `scripts/finalize.mjs` | Манифест зависимостей офлайн-сцен и отчёт о размере сборки |
| `tests/` | Зависимости физической модели, сброс, ошибки кэша и обновления |

В экранном режиме симуляция обновляется вне React, в VR — в XR animation loop. Одновременно работает только один источник времени. React получает снимки не чаще 10 раз в секунду. 2D, 3D и XR не рассчитывают собственные физические значения.

## Допущения физики

Это **учебная модель**, не инженерный симулятор и не цифровой двойник.

- По умолчанию в чистой модели: масса 1600 кг, радиус колеса 0,32 м, батарея 60 кВт·ч. В приложении параметры берутся из выбранного профиля автомобиля; см. Garage v2.
- Базовая учебная модель: момент двигателя до 220 Н·м, ограничение мощности 75 кВт. В гараже используются ограничения выбранного автомобиля; тяга отключается при торможении.
- КПД двигателя 0,90, редуктора 0,96. Для движения: `ω_motor = v/r × i`, `M_wheels = M_motor × i × η_gear`, `P_motor = M_motor × ω_motor`.
- Мощность считается на средней скорости шага интегрирования, показанные обороты — в конце шага. Это даёт небольшое различие `P` и произведения текущих индикаторов при разгоне.
- При рекуперации колесо отдаёт энергию через потери редуктора и двигателя. Обратный момент рассчитывается с учётом направления потока. Возврат меньше потери кинетической энергии.
- Левое/правое колесо: средняя скорость умножается на `1 ∓ 0,25 × поворот`; их среднее всегда совпадает с выходным валом. Это кинематическая иллюстрация, без модели шин и геометрии рулевого управления.
- Числа зубьев: 12 на входе, `12 × i` на выходе. Общий модуль зубьев пересчитывается, межосевое расстояние постоянно. Профиль зуба упрощён; нет расчёта контакта и прочности. Дифференциал показан схемой скоростей, без подробной геометрии сателлитов.
- Рекуперация ограничена 30–50 кВт в зависимости от учебного профиля (35 кВт в базовой модели) до потерь, моментом и скоростью; отключается ниже 0,5 м/с, плавно снижается с 90 до 98% заряда и при перегреве. Фрикционные тормоза обеспечивают оставшуюся силу.
- Заряд: интеграл мощности / ёмкость выбранного профиля, ограниченный 0–100%. Тепловая модель сосредоточенная: условные потери силового тракта + 2,5% потока батареи, теплоёмкость 180 кДж/К, отвод 450 Вт/К с охлаждением и 25 Вт/К без него, окружающая среда 25 °C. Это иллюстрация теплового баланса, а не точная температура ячеек.
- Фиксированный шаг 1/120 с. Скорость демонстрации меняет скорость учебного времени, не заданные тягу, передаточное отношение или физические зависимости. **Видимое вращение /60**, **тепловые процессы ×30** — подписано в интерфейсе.
- Нет пробуксовки, подвески, деградации ячеек, электрической схемы инвертора, трёхфазного расчёта или температурных пределов реальной батареи.

## PWA и офлайн

Оболочка кэшируется при установке service worker. «Сохранить офлайн» скачивает зависимости выбранной сцены; размер показан до загрузки, статус устанавливается только после успешного завершения. При ошибке квоты незавершённый кэш удаляется. Кнопка удаления удаляет только выбранную копию. Зависимости могут дублироваться между кэшами сцен; это простой вариант выборочного офлайн-кэша.

Имена кэшей привязаны к хешу сборки. Новая версия ждёт явного обновления на паузе. Старые кэши очищаются при активации новой версии; сохранённые сцены после обновления нужно скачать повторно. Обновляйте приложение, завершив эксперименты во всех открытых вкладках. Первое посещение без сети не поддерживается. Для офлайн-проверки используйте production build, а не Vite dev server.

## Проверка на телефоне

1. Опубликуйте `dist/` на HTTPS-хостинге. Откройте URL на телефоне.
2. Проверьте 360 и 390 px, поворот экрана, вращение одним пальцем и масштаб двумя. Важные параметры доступны под сценой; панель сворачивается.
3. Запустите тягу, измените нагрузку, переключите сцены, затем 2D. Значения должны совпадать; счётчики не должны сбрасываться при смене представления.
4. Сохраните сцену, дождитесь статуса, выключите сеть, закройте и снова откройте приложение. Проверьте сохранённую сцену и инструкцию; несохранённая 3D-сцена может перейти в 2D.
5. Chrome/Edge: установка через меню/предлагаемую кнопку. iOS Safari: «Поделиться» → «На экран Домой».

## Meta Quest и HTTPS

1. В Quest Browser откройте HTTPS-адрес. Поддержка определяется `navigator.xr.isSessionSupported('immersive-vr')`, без проверки user-agent.
2. Откройте 3D-сцену, нажмите «Войти в VR», подтвердите разрешения. При ошибке остаётся экранное приложение.
3. Проверьте лучи обоих контроллеров, все кнопки панели, перенос боковой кнопкой, стик, выбор деталей и текст объяснения под панелью, возврат модели и выход.
4. Не требуется перемещение по комнате. Камера не перемещается принудительно. Hand tracking не реализован.
5. Упаковка под Meta Horizon OS — отдельный этап: проверьте текущие требования Meta к веб-приложениям, создайте пакет/идентификатор и настройте разрешения, подпись и магазин согласно официальной документации. PWA-манифест не публикует приложение в Horizon Store. Совместимость всех моделей гарнитур не заявляется.

## Проверки и ограничения

См. [отчёт проверки](docs/VALIDATION.md) и [размеры сборки](docs/build-report.json). Настоящие слабый телефон и Meta Quest в среде недоступны; целевые FPS и работа пространственного управления на устройстве **не подтверждены**. Инструмент браузера отсутствует, поэтому визуальные проверки размеров, касаний, настоящего Service Worker, XR-эмуляции и WebGL не выдаются за выполненные. Для них предусмотрен ручной список в отчёте.

Все геометрии и иконки созданы процедурно в проекте; внешних моделей, фото, шрифтов и ассетов нет. Системные шрифты работают без сети.
